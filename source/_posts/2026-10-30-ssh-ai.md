# 琳东SSH：把重复运维交给 AI 的桌面深度运维终端（附上手教程）

> 官网传送门：**https://ssh.ldnet.tech/** ｜ 当前版本 v1.3.1（2026-10-26 发布）｜ 支持 Windows / macOS / Linux

作为一个天天和服务器打交道的站长，最烦的不是技术难题，而是**重复**：十几台机器逐台敲同一条巡检命令、逐台查日志、逐台对配置。最近体验了一款国产的开源思路产品——**琳东SSH**，一款 AI-Native 的桌面 SSH 客户端，核心理念一句话概括：**把重复交给 AI，把决策留给自己**。

![琳东SSH 首页](/tutorial/ssh/hero.png)

它不是一个简单的"套壳 ChatGPT 终端"，而是围绕**批量效率、人机协作、数据安全**三条主线做了完整的工程化。下面结合截图带大家过一遍核心能力和上手流程。

## 二、核心功能速览

### 1. 多主机 Tab 批量运维 —— 告别逐台敲命令

最多支持 **16 台主机并发连接**，每台主机独立 Tab、会话互不干扰。勾选「多主机」后，AI Agent 会按 Tab 顺序**逐台执行任务并自动切换上下文**，执行结果差异一目了然。

![多主机批量运维](/tutorial/ssh/batch.png)

典型场景：

- **批量巡检**：一条指令跑完全部机器 —— 磁盘水位、负载、异常进程、证书到期时间统一收集汇总；
- **对齐配置**：以某台基准机为准，批量核对/修复其余机器的配置漂移；
- **批量变更**：统一创建账号、下发文件、重启服务，按顺序安全推进。

### 2. 双终端分屏 —— AI 干活、人盯关键

左侧是你手动输入的交互式 Shell，右侧实时展示 Agent 的每一步工具调用轨迹。需要密码输入、sudo 提权等人工交互时，系统**自动转交交互 Shell** 给你，完成后 Agent 继续接管——敏感操作永远不会绕过人工确认。

![双终端分屏](/tutorial/ssh/split.png)

### 3. 30+ Agent 工具链

内置 30 余种运维工具供 Agent 按需组合调用：命令/脚本执行、SFTP 读写、grep/find 检索、日志追踪与摘要、服务与端口管理、配置语法校验、子任务委派、执行计划编排……覆盖日常运维的绝大多数操作面。

![Agent 工具链](/tutorial/ssh/tools.png)

### 4. 多模型多厂商 API —— 不绑定单一厂商

预设 **11 家主流模型服务**（DeepSeek、OpenAI、Claude、Gemini、通义千问、智谱 GLM、Kimi、硅基流动、OpenRouter、Ollama、小米 MiMo），填 Key 即用；同时支持**自定义端点**，任何兼容 OpenAI 协议的网关/私有部署都能接入。

![多模型多厂商 API](/tutorial/ssh/models.png)

不同任务可以选不同模型：日常巡检用低成本模型，复杂排障再切旗舰模型，成本和效果都可控。

### 5. 智能上下文与零知识加密同步

- **Token 预算可视化**：实时显示会话 Token 占用与预算余量；
- **超长会话自动压缩**：接近 70K 软上限时自动摘要压缩早期对话，长任务不中断；
- **对话回滚**：可回滚到任意历史节点继续对话，误操作后从分叉点换条路接着走；
- **零知识加密云端备份**：主机列表、快捷提示词、快捷命令多设备准实时同步，采用 `aiss_*` + `enc_*` 双密钥体系，数据在本地加密后才上传，**服务器永远看不到明文**。

![智能上下文与数据同步](/tutorial/ssh/sync.png)

### 6. 安全可控 —— 敢把生产机交给 AI 的前提

- **只读文件系统模式**：默认约束 Agent 只读不写，排查类任务零风险；
- **高危命令拦截**：`rm -rf /`、磁盘格式化等危险操作内置拦截规则；
- **写前备份**：修改文件前自动创建备份副本，改错可回退；
- **ask_user 确认机制**：关键步骤主动暂停等人工确认；
- **运维留痕可审计**：工具调用、命令执行全程留痕。

![安全可控](/tutorial/ssh/security.png)

另有**远端监控侧栏**（不离开终端查看 CPU/内存/进程/磁盘实时状态）和**快捷命令库**（高频命令一键发送），细节做得比较到位。

## 三、快速上手流程

1. **下载安装**：官网 https://ssh.ldnet.tech/ 下载对应平台版本；
2. **添加主机**：录入服务器 SSH 连接信息（支持主机分类管理，机器多也不乱）；
3. **配置模型**：设置里选一家模型服务填入 API Key，或配一个 OpenAI 兼容的自定义端点；
4. **开始使用**：先在单机上试个只读任务（比如"帮我检查磁盘水位"），感受 Agent 的工具调用轨迹；
5. **批量操作**：多台机器勾选「多主机」，一条指令批量巡检，看它逐台执行汇总结果；
6. **同步备份**：需要多设备使用的话，开启零知识加密同步，注意保存好只显示一次的两把密钥。

## 四、适合谁用

- 管理多台服务器的**独立开发者 / 站长 / 自媒体技术号**；
- 需要**批量巡检和变更**的中小团队运维；
- 想尝试 **AI 辅助运维**但担心安全性的同学（只读模式 + 高危拦截 + 写前备份，闸门齐全）。
